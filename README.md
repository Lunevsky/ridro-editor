# Редактор схем маршрутов RidroExpress

Схемы маршрутов в фирменном стиле ЧТУП «RidroExpress» (MTA Province #6): остановки ставятся кликом, линия сама прокладывается по дорогам, экспорт PNG 1920×1080.

Сайт: https://lunevsky.github.io/ridro-editor/ · основной сайт компании: https://lunevsky.github.io/ridroexpress/

Работает и без сервера: можно открыть `index.html` двойным кликом.
